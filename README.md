# WARDOGS L81 Mortar Calculator

Lightweight, browser-only WARDOGS L81 mortar fire-solution calculator.

## GitHub Pages

This repository is designed to publish directly from the `main` branch root.

GitHub:
1. Settings
2. Pages
3. Build and deployment → Source: **Deploy from a branch**
4. Branch: **main**
5. Folder: **/(root)**
6. Save

The site will then be available at:

`https://caeth.github.io/wardogs-mortar/`

## Features

- Mortar and target coordinate input
- Bearing / azimuth
- Range
- L81 elevation in mils
- Community firing-table interpolation
- Out-of-range detection
- Copy fire solution
- Remembers previous coordinates locally
- No server, database, analytics, or external dependencies

## Current limitations

- L81 only
- Flat-ground solution
- No terrain-height correction
